# Auto Skill Up

Crie uma nova landing page completa e responsiva para o produto Formação Mecânico Automotivo.

IMPORTANTE: esta página deve ser uma nova versão estratégica da oferta, inspirada na lógica comercial de uma oferta de referência, mas NÃO deve copiar textos, identidade visual, layout, imagens, nomes, elementos gráficos ou estrutura visual específica da referência.

O objetivo é criar uma página própria, moderna, profissional e altamente orientada à conversão para tráfego de Meta Ads.

PRODUTO

Nome:
Formação Mecânico Automotivo

Categoria:
Curso profissionalizante online de mecânica automotiva.

Posicionamento:
Uma formação para pessoas que querem aprender mecânica automotiva começando do zero, através de aulas práticas e organizadas, desenvolvendo uma habilidade que pode ser útil para cuidar do próprio veículo, trabalhar na área ou futuramente prestar serviços.

PROMESSA CENTRAL

A comunicação deve trabalhar a seguinte ideia:

Você não precisa nascer sabendo mecânica. Pode começar do zero, aprender passo a passo e desenvolver uma habilidade prática na área automotiva.

Evite promessas irresponsáveis como:

“Ganhe R$10 mil”

“Fique rico”

“Renda garantida”

“Emprego garantido”

“Clientes garantidos”

Podemos falar sobre possibilidade de desenvolver uma habilidade profissional e futuramente utilizá-la para prestação de serviços, mas sem garantir resultados financeiros.

EXPERIÊNCIA MOBILE

A maior parte do tráfego virá de Meta Ads.

Portanto:

Priorizar mobile-first.

Botões grandes.

Textos curtos.

Cards empilhados.

Preços extremamente legíveis.

CTA fácil de tocar.

Espaçamento confortável.

Evitar blocos enormes de texto.

Garantir carregamento rápido.

Adicionar botão CTA estrategicamente ao longo da página.

COMPORTAMENTO DOS CTAs

Todos os botões de compra devem utilizar links facilmente editáveis posteriormente.

Criar uma constante/configuração central para os links:

PRO_CHECKOUT_URL

Assim será fácil alterar os links de checkout posteriormente sem procurar botão por botão.

OBJETIVO FINAL

A página precisa fazer o visitante entender rapidamente:

“Eu consigo começar do zero.”

Depois:

“São mais de 80 aulas e existe uma formação estruturada.”

Depois:

“Por R$27,90 eu recebo muito mais do que simplesmente as aulas.”

E finalmente:

“O risco é baixo, então vale a pena começar.”

A prioridade deve ser:

CLAREZA → DESEJO → VALOR PERCEBIDO → CONFIANÇA → OFERTA → CTA

Não criar uma página excessivamente longa apenas para parecer completa.

A página deve ser visualmente forte, rápida, moderna e construída especificamente para conversão de tráfego frio vindo de Meta Ads.
